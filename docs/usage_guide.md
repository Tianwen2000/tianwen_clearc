# Tianwen ClearC 使用说明

日期：2026-05-21

## 1. 启动程序

在项目目录执行：

```bash
cd /Users/a123/PycharmProjects/pipenv_project/deng/tianwen_clearC
source .venv/bin/activate
pip install -e .
tianwen-clearc
```

如果不想激活虚拟环境，也可以直接执行：

```bash
cd /Users/a123/PycharmProjects/pipenv_project/deng/tianwen_clearC
.venv/bin/python -m pip install -e .
.venv/bin/python -m tianwen_clearc.app
```

## 2. 基本使用流程

1. 点击顶部的“选择”按钮。
2. 选择要扫描的磁盘或目录，例如 C 盘、Downloads、项目目录等。
3. 点击“扫描”。
4. 等待左下角状态栏显示扫描进度。
5. 扫描完成后，上方显示目录树，下方显示自动折叠到当前区域内的 Treemap 矩形图；大目录矩形内部会继续预览它的子目录和文件。
6. 矩形越大，表示文件或目录占用空间越大；很小的项目也会保留可见区域。
7. 单击目录树或矩形都可以选中项目，并在对应区域上方的横幅查看路径和大小。
8. 双击目录矩形可以进入这个目录。
9. 点击“上级”可以回到上一层。
10. 点击“导出”可以导出当前视图的 CSV 或 JSON 报告。

颜色规则：黄色/橙黄色表示文件夹目录；文件会按扩展名分配不同颜色，例如图片偏绿色、压缩包偏蓝色、视频偏红色、日志偏紫色、Python 文件偏青绿色，其他文件按扩展名自动分配颜色。

## 3. 过滤功能

顶部过滤栏支持四类条件：

- 关键字：按名称或路径搜索，例如 `cache`、`log`、`venv`。
- 扩展名：按文件后缀过滤，例如 `*.log`、`jpg`、`.zip`。
- 最小 MB：只显示大于指定大小的项目，例如 `100` 表示至少 100 MB。
- 类型：全部、仅文件、仅目录。

填写条件后点击“应用过滤”。点击“清空”会恢复完整扫描结果。

## 4. 右键菜单

在 Treemap 矩形上右键，可以使用：

- 打开：用系统默认方式打开文件或目录。
- 在资源管理器中显示：定位到这个文件或目录。
- 复制路径：把完整路径复制到剪贴板。

macOS 开发环境下会使用 Finder；Windows 上会使用资源管理器。

## 5. 导出报告

点击“导出”后可以选择：

- CSV：适合 Excel、WPS、表格工具查看。
- JSON：保留树结构，适合后续程序读取或调试。

导出内容包含路径、名称、类型、大小、文件数、目录数、修改时间和扫描跳过原因。

## 6. 注意事项

- 扫描系统目录时，部分路径可能因为权限不足无法读取，程序会显示为“无权限跳过”并继续扫描；点击状态栏右侧的“无权限跳过 N 项”可以查看路径和原因。扫描过程中临时消失的缓存/日志文件会静默忽略，不计入跳过数量。
- 第一版默认跳过符号链接，避免重复统计或循环扫描。
- 当前版本还没有删除功能，避免误删文件。
- Windows `.exe` 需要在 Windows 环境用 PyInstaller 打包。
